# 数据结构实践 —— 两个选题

《数据结构实践》课程的两份任务书，各自实现成独立、可直接运行的项目。

## 目录结构

```

├── HANDOFF.md                     开发进度记录

│   └── 选题一_城市交通路径导航系统/
│       ├── run.py                 程序入口
│       ├── src/                   源码（graph / solver / ui 三层解耦）
│       ├── data/                  四份路网数据（含广州、北京真实地铁）
│       ├── tests/                 算法测试、界面测试

│       ├── docs/                  实验报告、算法过程讲解、界面截图
│       └── README.md              运行与使用说明
├── 第二部分/
│   └── 选题二_任务调度模拟器/
│       ├── run.py
│       ├── src/                   源码（models / scheduler / engine / ui）
│       ├── data/                  五份任务数据
│       ├── tests/                 算法测试、交叉验证、界面测试
│       ├── tools/                 对比实验脚本
│       ├── docs/                  实验报告、界面截图
│       └── README.md

    └── 实验要求解读.md             两份任务书的逐条解读
```

## 两个选题

| | 第一部分 · 城市交通路径导航系统 | 第二部分 · 任务调度模拟器 |
|---|---|---|
| 核心问题 | 图上最短路径与最少换乘 | 单处理器任务调度策略的比较 |
| 算法 | Dijkstra、A\*、最少换乘 BFS | FCFS、非抢占式优先级、时间片轮转 |
| 关键数据结构 | 邻接表、二叉堆 | FIFO 队列、二叉堆 |
| 界面亮点 | 网络图缩放平移、搜索动画、换乘指引 | 任务表实时刷新、甘特图、算法对比 + 甘特图预览 |
| 数据 | 广州地铁全网（真实，310 站）、北京地铁主干（真实，224 站）、65 站、14 站 | 五份任务数据 |
| 测试 | 9 组 3060 + 5 组 1884 + 5 组 52 个断言 | 17 组 30627 + 3 组 2567 + 8 组 64 个断言 |
| 报告 | `docs/实验报告.md`、`docs/算法过程讲解.md` | `docs/实验报告.md` |

## 运行

两个项目都只需要 Python 自带的 Tkinter，**不依赖任何第三方库**。

```bash
cd 第一部分/选题一_城市交通路径导航系统
py run.py
```

```bash
cd 第二部分/选题二_任务调度模拟器
py run.py
```

各自目录下的 `README.md` 有完整的操作说明、数据格式与测试命令。

## 运行测试

```bash
cd 第一部分/选题一_城市交通路径导航系统 && py tests/test_algorithms.py && py tests/test_guangzhou.py && py tests/test_ui.py
```

```bash
cd 第二部分/选题二_任务调度模拟器 && py tests/test_scheduler.py && py tests/test_cross_check.py && py tests/test_ui.py
```
